## Services Pattern
- The `/src/app/services` directory contains custom React hooks for API interactions
- Each service file follows a consistent pattern:
  - Uses "use client" directive for client-side rendering
  - Exports TypeScript interfaces for request payloads and response types
  - Implements a custom hook that returns API methods and state (isLoading, error)
  - Each API method handles its own error handling and loading state
  - Uses axios for HTTP requests via a centralized axiosInstance
  - Follows RESTful API patterns with endpoints organized by resource
- Key services include:
  - `useAuthentications.ts` - Handles user login and authentication
  - `useProjects.ts` - Project management operations
  - `useTeams.ts` - Team management
  - `useUsers.ts` - User management
  - `useRequirements.ts` - Requirements management
  - `useDivisions.ts` - Division management
  - `useMediaObject.ts` - Media file handling
  - `useWorkflow.ts` - Workflow management (newly created)
